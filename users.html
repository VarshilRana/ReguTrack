Access boundaries

Current ReguTrack workspace roles.

Admin

Platform-wide oversight and access administration.

  • Separate Admin dashboard and navigation
  • View platform-wide records and audit activity
  • Access the user directory
  • Manage regulatory sources under database policy

User

Standard workspace access for regular account holders.

  • Work with own product records and CTD dossiers
  • Prepare gap and impact assessments
  • View regulatory intelligence and deadlines
  • Cannot approve assessments or manage accounts
Account administration and role changes are Admin-only. The browser never receives a Supabase service/secret key. Role assignment requires an authenticated server-side operation that verifies the caller's Admin role.
